========================================
 Unbound 使用教程（新手版）
========================================

先看这一句：绕配置会清空手机资料，做之前先备份。
下面按顺序做，不用懂技术也能跟着走。

重要：所有需要的东西都已经打包在程序里，
你不需要去找别的工具、也不需要准备任何文件。


----------------------------------------
 一、打开软件
----------------------------------------
1. 把压缩包解压出来（别在压缩包里直接双击）
2. 双击 apple-toolkit.exe
3. 如果 Windows 提示"已保护你的电脑"
   点"更多信息" -> 点"仍要运行"


----------------------------------------
 二、连接手机
----------------------------------------

【苹果手机】
1. 用数据线连到电脑
2. 手机上会弹出"信任此电脑"，点"信任"，再输锁屏密码
3. 左上角变成"设备已连接"就成功了

【安卓手机】
1. 手机上打开：设置 -> 关于手机 -> 连续点"版本号"7 次
   （会提示"你已进入开发者模式"）
2. 回到设置 -> 开发者选项 -> 打开"USB 调试"
3. 插上数据线，手机上点"允许 USB 调试"
4. 回到软件，标题下面点"Android"

（adb 已经在程序里，不用你装。第一次打开程序时它会自己解出来。）


----------------------------------------
 三、切换苹果 / 安卓
----------------------------------------
标题 Unbound 下面有三个按钮：

    [自动]  [iOS]  [Android]

- 自动：插什么认什么（默认，一般不用动）
- 手动点可以强制切换


----------------------------------------
 四、看手机信息
----------------------------------------
左栏"设备总览"：能看到机型和参数
苹果手机再点"详细验机" -> "读取 / 刷新详细信息"，能看到更多


----------------------------------------
 五、备份（苹果手机）
----------------------------------------
左栏"备份与刷机" -> "备份手机资料" -> 选一个文件夹 -> 等它跑完
要恢复：同一页 -> "从备份恢复资料"


----------------------------------------
 六、绕配置（重点）
----------------------------------------
【必须看清】
  * 会清空手机里的所有资料
  * 先备份！先备份！先备份！
  * 只支持 iOS 27 及以下，再高的版本不行

第 1 步：连好苹果手机，确认左上角"设备已连接"

第 2 步：在电脑上随便新建一个空文件夹，比如 D:\任务
        （只要是个空文件夹就行，不用往里面放任何东西）

第 3 步：左栏"解锁与配置" -> "iOS 绕配置 . 准备" -> 选 D:\任务
        等它跑完。看到"已从内置资源放入 …"就说明对了。
        下面还会列出改写了哪些项，出现"跳过 xxx"是正常的，不影响。

第 4 步：再点"iOS 绕配置 . 开始" -> 输入手机序列号 -> 开始
        手机会重启一两次，别拔线，等它跑完。

【序列号在哪】
左栏"设备总览"里能看到，"详细验机"里也有。

【iOS 27 要不要另外填口令】
不用。程序自带默认口令。除非你用的是别处的备份，才需要自己填。


----------------------------------------
 七、绕激活锁（要手机已越狱）
----------------------------------------
只有老机型能越狱：iPhone 5s 到 iPhone X
再新的机型没有越狱，这条路走不通

步骤：
1. 连好手机，确认左上角"设备已连接"
2. 随便选一个空文件夹当任务目录
3. "iOS 绕激活锁 . 准备" -> 等它跑完
4. "iOS 绕激活锁 . 开始" -> 输入序列号 -> 开始

替换件、上传工具、脚本全部在程序里，不需要你准备文件。
前提只有一条：手机已经越狱，并且开好了 root SSH（默认密码 alpine）。


----------------------------------------
 八、支持作者
----------------------------------------
用满 20 分钟会自动弹一个窗口
也可以手动打开：左栏最下面"关于 Unbound" -> "支持这个项目"

扫不上码怎么办：
1. 点图片放大，再扫
2. 还不行就点"保存原图到桌面"，用手机微信/支付宝从相册识别
3. 微信赞赏码只能微信自己识别，别的扫码器读不出来


----------------------------------------
 九、常见问题
----------------------------------------

Q：按钮全是灰的，点不动
A：手机没连上。先看左上角是不是"设备已连接"。

Q：安卓手机看不到设备
A：先确认手机上打开了 USB 调试、并且点了"允许"。
   还不行就换个 USB 口或数据线，再点一次"查看安卓设备"。

Q：点"准备"之后，任务文件夹里多了一堆文件，正常吗
A：正常。那是程序自己解出来的工具和备份，不要去改它、不要删。

Q：点"开始"跑到一半失败
A：别重复点。把界面上红色的报错文字发给我。
   手机如果被清空了，可以用恢复模式救回来
   （电脑上装 iTunes 或 Apple Devices）。

Q：右下角版本号不对
A：那是旧版本。关掉程序，重新解压最新的包。

Q：程序为什么这么大（快 100 MB）
A：因为绕配置和绕激活锁要用的工具、备份、替换件全部打包在里面了。
   这样你不用去翻别的工具。代价就是体积大。


----------------------------------------
 十、几条硬提醒
----------------------------------------
1. 绕配置清空资料，没有后悔药
2. 绕配置不能解除 Apple ID 账户锁
3. 刷机或绕配置前，电量保证 50% 以上
4. 全程只插一台手机，别插多台，会认错设备
5. 我没有在真机上验证过绕配置，不保证每台都成功
   出问题先停下，别反复试
